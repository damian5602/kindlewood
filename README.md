# Kindlewood

Wokselowa gra survival (Godot). To repozytorium zawiera tylko gotowe wersje gry do pobrania — kod źródłowy nie jest tu publikowany.

**Pobieranie:** [najnowsza wersja](https://github.com/damian5602/kindlewood/releases/latest) — pobierz zip, rozpakuj i uruchom `Kindlewood.exe`.
Kolejne wersje gra pobiera sama: w menu (prawy dolny róg) pojawi się przycisk „Aktualizuj”.
